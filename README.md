# Bilim Hub — учебная платформа

Bilim Hub содержит личный кабинет студента, авторизацию через Supabase, персональные предметы и тренировочные тесты.

## Требования

- Node.js 20.9 или новее;
- npm;
- проект Supabase.

## Запуск

В терминале из папки `bilim-hub`:

```bash
npm install
npm run dev
```

Открой http://localhost:3000.

## Настройка Supabase

1. Создай проект на https://database.new.
2. В Supabase открой Connect / API Keys и скопируй **Project URL** и **Publishable key**.
3. Скопируй `.env.example` в `.env.local` и вставь значения:

```env
NEXT_PUBLIC_SUPABASE_URL=https://YOUR_PROJECT_REF.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_YOUR_KEY
```

Не публикуй `.env.local` и не отправляй ключи в открытые чаты. Secret/service-role key не нужен.

## SQL-миграции

Для первого запуска следуй последовательности:

1. `supabase/schema.sql` — профили, предметы, RLS и триггер регистрации.
2. `supabase/quizzes.sql` — рубежки, пробная сессия, вопросы, попытки и защищённая проверка ответов.

Если профили и предметы уже работают, **не запускай `schema.sql` повторно**. Запусти только `supabase/quizzes.sql` через Supabase → SQL Editor → New query → Run.

`quizzes.sql` можно запускать повторно: таблицы, тесты и вопросы создаются идемпотентно. Миграция добавляет стартовые тесты уже зарегистрированным студентам и расширяет триггер, чтобы новые студенты также получали тесты автоматически.

## Настройка подтверждения почты

В Supabase → Authentication → URL Configuration:

- Site URL: `http://localhost:3000`;
- Redirect URL: `http://localhost:3000/auth/callback`.

Для production добавь адрес опубликованного сайта в Site URL / Redirect URLs.

## Возможности версии 0.4

- адаптивный тёмно-фиолетовый кабинет;
- регистрация, вход, выход и подтверждение email;
- серверная проверка авторизации;
- личные предметы с добавлением, удалением и сохранением прогресса;
- отдельные тренировочные рубежки по четырём стартовым дисциплинам;
- пробная смешанная сессия;
- вопросы с вариантами ответов и таймер;
- сохранение попыток и результатов в Supabase;
- Row Level Security для тестов и истории результатов;
- правильные ответы не выдаются браузеру: серверная функция проверяет ответы и рассчитывает балл.

## Примечание

В версии 0.4 вопросы и тесты — стартовый демонстрационный набор. Их можно расширять и редактировать как контент курса на следующем этапе.
